# TFY4220 Faste stoffers fysikk

Interaktivt kompendium i [TFY4220](https://www.ntnu.no/studier/emner/TFY4220) ved NTNU:
moduler med quiz, flashcards, formelsamling og begreper. Les det på
**[fastestoffer.martinsundal.no](https://fastestoffer.martinsundal.no)**.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
